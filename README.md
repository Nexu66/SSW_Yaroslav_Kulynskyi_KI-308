# SSW_Yaroslav_Kulynskyi_KI-308
## Курсова робота з предмету "Системне програмне забезпечення"

- Логування запусків додатків: Фіксація точного часу відкриття та закриття будь-якого вікна (програми). Ви зможете побачити, скільки часу користувач провів, наприклад, у браузері чи грі.
- Кейлоггер (Keylogging) з фільтром: Запис натискань клавіш.
- Моніторинг підключення USB-пристроїв: Сповіщення та запис у лог кожного разу, коли вставляється флешка або інший пристрій.
- Контроль буфера обміну: Збереження історії всього, що користувач копіював (текст, посилання).
- Відстеження стану живлення: Запис подій виходу з режиму сну, блокування екрана або низького заряду батареї.
- Генерація "Теплової карти" активності: Звіт у вигляді графіка, який показує піки активності користувача протягом дня (коли було найбільше кліків та натискань клавіш).
